CRAFT BRIEF — apply to this design (Ad Spy, a premium competitor-ad-intelligence tool for performance marketers). This is the standing design system; honor it unless the specific request overrides a point.

HIERARCHY: one clear focal point per screen, then a deliberate 2nd/3rd tier. Big confident key numbers (tabular figures); small quiet UPPERCASE tracked labels; calm body. If everything shouts, nothing is heard.

COLOR: dark, layered navy/charcoal surfaces (deepest canvas → panel → raised) for depth — NOT color. Text is white + cool grays with real contrast. ONE accent (electric blue) used SPARINGLY: active nav/tab, one primary button, small status dots. NEVER saturated blue as body or link text on dark (harsh, low-contrast); interactive text is light gray brightening toward white on hover. Status colors muted + semantic (soft green/amber/red), never neon.

TYPOGRAPHY: DM Sans, one tight consistent scale (don't invent sizes), tabular numerals for data, generous line-height for body. Weight carries hierarchy more than size.

SPACING: consistent 4/8px rhythm, generous even whitespace, strict grid alignment — nothing "roughly placed". Density is deliberate and even.

DEPTH (subtle, never flat, never garish): hairline borders (white 6–11%), soft diffuse shadows, gentle top→bottom surface gradients, a faint inner top highlight on cards. Restraint reads as expensive.

COMPONENTS: cards/chips/buttons/badges follow ONE reused pattern — same padding, radii, states. Consistency over per-element novelty.

RESTRAINT + ACCESSIBILITY: remove before adding; target adjective = calm, premium, trustworthy. Readable contrast on every text/bg pair; visible focus states; respect reduced-motion.

Stack note: standalone HTML mockup is fine, but keep structure clean/semantic so the look ports onto a real CSS-variable-driven app.
